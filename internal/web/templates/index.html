  • Multi-platform manifests & layers

    Resolves mutable tags to immutable sha256 digests, compares every architecture in an OCI image index, and maps image config build history to compressed layers without pulling filesystem blobs.

  • Signatures & identity claims

    Discovers OCI referrers and Cosign attachments, extracts X.509 signing certificates, Fulcio OIDC issuers, and Rekor log entries, and checks embedded cryptographic signatures separately from policy trust.

  • Build provenance & base lineage

    Decodes SLSA v0.2 and v1.0 source repositories, commits, workflows, and builders—then matches layer digest prefixes against provenance inputs and OCI annotations to link directly to underlying base images.

  • Published SBOMs & raw evidence

    Presents SPDX and CycloneDX software inventories with ecosystem and license breakdowns and searchable package tables, while keeping decoded JSON structures and raw artifact downloads one click away.

How inspection works

Public read-only inspection
Metadata only
Reads OCI manifests, image config JSON, OCI referrers, BuildKit index attestations, and Cosign metadata attachments. Container filesystem layers are never downloaded or executed.
No generation or scanning
Displays only metadata published by the image maintainer to the registry. Does not generate SBOMs or run vulnerability scans.
Immutable links
Mutable tags are resolved to sha256 digests before discovery. Links to platform variants, runtime bases, and build inputs navigate by immutable digest.
Verification boundaries
Explicitly separates discovered, decoded, embedded signature valid, and policy trusted states. Certificate chains, Rekor inclusion proofs, and trust policies are not evaluated.
